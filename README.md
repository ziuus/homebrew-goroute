# Homebrew Tap for GoRoute

Ultra-lightweight (<15MB RAM) LLM gateway and multi-agent router in Go.

## Installation

```bash
brew install ziuus/goroute/goroute
```

Or tap first:

```bash
brew tap ziuus/goroute
brew install goroute
```

## Documentation

Full documentation and quick start guide: [github.com/ziuus/goroute](https://github.com/ziuus/goroute)
